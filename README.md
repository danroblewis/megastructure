# Megastructure

A body of cells riding the currents of a vast machine. The world is a lattice-Boltzmann gas with heat, smoke, fuel and
living matter, simulated on the GPU in WebGL2; you are a cloud of cells with a sense of self that stretches, tears and
reforms. Play it at **https://danroblewis.github.io/megastructure/v2/** (installable, works offline).

- `v2/` — the game. `v2/DESIGN.md` is the design goal, `v2/ROADMAP.md` the plan, `v2/SCHEMES.md` the input schemes.
- `v1/` — the original CPU falling-sand prototype.
- `tools/` — dev server with remote error reporting and a DevTools driver for headless checks.

Run locally with any static server, e.g. `python3 -m http.server 8000`, then open `/v2/`.
